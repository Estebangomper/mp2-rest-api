# MP2: Data Processing REST API

This project is a FastAPI REST API that reuses my MP1 data pipeline. `GET /health` returns the API status and version. `POST /upload` accepts a CSV file, stores it in memory, and returns its ID, filename, rows, columns, and column names. `GET /datasets/{dataset_id}` returns up to `limit` rows of a stored dataset. `POST /datasets/{dataset_id}/process` takes a JSON config, validates and cleans the dataset with the MP1 functions (required and numeric columns, duplicates, missing values, outliers), replaces the stored dataset, and returns a cleaning report. Every request is logged by middleware with a request ID, method, path, status code, and duration, and the ID is returned in the `X-Request-ID` header. Tests are in `tests/` and run with `python -m pytest tests -v`.
